## 🎯 Quick Start

### 🔧 Installation

```bash
# Clone the repo
git clone https://github.com/vannu07/Sentiment-analysis.git
cd Sentiment-analysis

# Install dependencies  
pip install -r requirements.txt

# Launch the app
python app.py
```

### 🎮 Launch Applications

<div align="center">

| 🎯 App | 🚀 Command | 🌐 URL | 📝 Purpose |
|--------|------------|--------|-------------|
| **Web App** | `python app.py` | `localhost:5000` | Main interface |
| **Dashboard** | `streamlit run dashboard.py` | `localhost:8501` | Analytics |

</div>
